# Documento Funcional: Calculadora Básica

## Propósito
El propósito de este sistema es proporcionar una calculadora básica que permita realizar operaciones aritméticas simples: suma, resta, multiplicación y división.

## Funcionalidades
- **Suma**: Permite sumar dos números.
- **Resta**: Permite restar un número de otro.
- **Multiplicación**: Permite multiplicar dos números.
- **División**: Permite dividir un número entre otro, manejando la excepción de división por cero.

## Requisitos Técnicos
- Lenguaje de programación: Python 3.x
- Entorno de desarrollo: Cualquier IDE o editor de texto que soporte Python.

## Ejemplos de Uso
1. Sumar 5 y 3:
   - Entrada: `5 + 3`
   - Salida: `8`
   
2. Restar 10 de 4:
   - Entrada: `10 - 4`
   - Salida: `6`
   
3. Multiplicar 7 por 6:
   - Entrada: `7 * 6`
   - Salida: `42`
   
4. Dividir 8 entre 2:
   - Entrada: `8 / 2`
   - Salida: `4`
   
5. Dividir 5 entre 0:
   - Entrada: `5 / 0`
   - Salida: `Error: División por cero`
