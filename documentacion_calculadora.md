# Documentación Funcional de la Calculadora

## Introducción
Esta documentación describe las funcionalidades de una calculadora simple que permite realizar operaciones aritméticas básicas.

## Funcionalidades

### 1. Sumar
- **Descripción**: Permite sumar dos números.
- **Entrada**: Dos números (a, b).
- **Salida**: La suma de a y b.
- **Ejemplo**: Sumar 2 y 3 devuelve 5.

### 2. Restar
- **Descripción**: Permite restar un número de otro.
- **Entrada**: Dos números (a, b).
- **Salida**: La resta de a menos b.
- **Ejemplo**: Restar 5 de 10 devuelve 5.

### 3. Multiplicar
- **Descripción**: Permite multiplicar dos números.
- **Entrada**: Dos números (a, b).
- **Salida**: El producto de a y b.
- **Ejemplo**: Multiplicar 4 por 5 devuelve 20.

### 4. Dividir
- **Descripción**: Permite dividir un número entre otro.
- **Entrada**: Dos números (a, b).
- **Salida**: El cociente de a entre b.
- **Ejemplo**: Dividir 10 entre 2 devuelve 5.
- **Nota**: No se puede dividir entre cero.

## Interfaz de Usuario
La calculadora tendrá una interfaz simple con botones para cada operación y un campo de entrada para los números.

## Requisitos
- Debe ser capaz de manejar entradas no válidas (por ejemplo, letras en lugar de números).
- Debe mostrar mensajes de error apropiados.

## Conclusión
Esta calculadora simple proporciona una interfaz fácil de usar para realizar operaciones aritméticas básicas, siendo útil para usuarios que necesitan realizar cálculos rápidos.
