# Calculadora Básica en Python

## Descripción

Esta es una calculadora básica implementada en Python que permite realizar las operaciones aritméticas fundamentales: suma, resta, multiplicación y división.

## Operaciones Soportadas

1. **Suma**: Suma dos números.
2. **Resta**: Resta el segundo número del primero.
3. **Multiplicación**: Multiplica dos números.
4. **División**: Divide el primer número por el segundo (no se permite la división entre cero).

## Ejemplos de Uso

- Para sumar dos números:
  ```
  Ingrese el primer número: 5
  Ingrese el segundo número: 3
  Resultado: 8
  ```

- Para restar dos números:
  ```
  Ingrese el primer número: 10
  Ingrese el segundo número: 4
  Resultado: 6
  ```

- Para multiplicar dos números:
  ```
  Ingrese el primer número: 7
  Ingrese el segundo número: 6
  Resultado: 42
  ```

- Para dividir dos números:
  ```
  Ingrese el primer número: 8
  Ingrese el segundo número: 2
  Resultado: 4.0
  ```

## Instrucciones para Ejecutar el Programa

1. Asegúrate de tener Python instalado en tu sistema.
2. Descarga el archivo `calculadora.py`.
3. Ejecuta el programa desde la línea de comandos:
   ```
   python calculadora.py
   ```

4. Sigue las instrucciones en pantalla para realizar las operaciones deseadas.
